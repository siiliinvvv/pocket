# 完整说明文档

> 这份文档是项目的完整说明书：功能清单、48 个 JS 模块逐个说明、数据结构、部署方式、历次改动记录。
> 想快速了解项目，看仓库根目录的 [README](../README.md) 就够了。

---

> 个人知识收纳应用（原名《我的百宝箱》）。纯前端、无需构建；另附一个零依赖 Node 服务，用于真实 AI 资讯抓取、大模型转发与分享数据快照。
>
> **本文档按当前代码逐项核对后编写**：第三章列出的功能都能在第四章的模块里找到实现；早期批次做过、后来被移除的界面（例如列表视图切换按钮、侧栏时间条）不再当作现有功能列出。历史改动见第十章。

## 一、三种使用方式

| 方式 | 怎么开 | 能力差异 |
|---|---|---|
| 部署站点 | 自己的域名 + `?sharecode=<分享码>`（首次务必带完整 `?sharecode=` 建立会话，否则静态资源可能 403） | 全功能；AI 资讯走服务端真实 RSS；分享快照可读写 |
| 本地服务 | 目录下 `npm start`（`node server.js`），浏览器开 `http://localhost:<PORT>` | 全功能；接口与线上一致，数据在本机浏览器 |
| 直接双击 | 双击 `index.html`（`file://`） | 除「导出分享版」外都能用；AI 资讯回退公共 RSS 代理（可能被限流）；导出会因浏览器安全策略缺样式脚本 |

数据默认只存在本机浏览器；需要多设备时在设置里接 GitHub 私有仓库，或用 JSON 备份迁移。

## 三、功能清单

### 3.1 内容与收集

- **六种条目类型**：文字笔记、照片、文件（任意格式）、网页链接、多维表格（类型 `grid`）、画布（类型 `canvas`）。主页与分类页以画廊卡片展示，缩略图懒加载。
- **新建入口**：新建富文本笔记、新建链接、新建多维表格、新建画布；批量上传照片/文件（可多选）。
- **拖入即收**：把外部文件拖进页面即上传（有全屏「松手即可收纳进来」提示）。
- **多级收纳夹**：任意层级的新建 / 重命名 / 删除；拖拽可换父级；把分类拖到另一个分类的**上/下边缘**是同级排序，拖到**中间**则变成它的子分类。
- **分类页**：多级面包屑导航；分类横幅背景可换（📷 上传、✕ 清除）；分类图标点一下循环换 emoji；右上角可选每行显示 2 / 3 / 4 张卡片。
- **空间与头像**：侧栏空间名点击即改名；头像支持上传图片 / 换 emoji / 清除，全站（含分享版）统一读取。
- **照片处理**：上传自动压缩（最长边 1400px、JPEG 0.85），大图点开进灯箱，可左右切换、下载原图。
- **文件上限**：默认单文件 50MB（设置里可调到 5–90MB）；超过上限时只登记文件名与大小、不保存内容，卡片仍可点开阅读或编辑时手动补齐。

### 3.2 阅读与编辑

- **内置阅读器（📖 HTML / PDF 文库）**：支持 HTML、PDF、纯文本与常见代码文件、Markdown、Word `.docx`；左侧 **列表 / 目录 / 标注 / 关联** 四个页签；可加附件，可导出 HTML / Markdown / 直接打印。
- **划线标注（阅读器内）**：在正文里选中一段文字，会浮出「高亮 / 下划线 / 波浪线 / 批注」——点一下即存进这篇文档；点已有标注可以写 / 改批注或删除。左侧「🖍 标注」页签按顺序列出本文全部标注（类型徽标 + 引文 + 批注），点一条跳回原文位置。标注跟着文档走：重新打开、换设备、云端同步合并后都能落回同一段文字（原文改动过大时不再强行定位，也不会错标到别处）。顶栏也有「🖍 标注」按钮，手机端直接打开标注页签。手机 / 平板上的工具条固定在屏幕底部（避开系统选字后弹出的「复制 / 查询」气泡），长按时浏览器原生菜单也不再弹出。
- **PDF 全文索引**：打开 PDF 时按需从 CDN 加载 pdf.js，逐页抽取文本建立索引（需联网）；从搜索结果点开 PDF 会直接跳到命中的那一页。注意：全局搜索对 PDF 只按文件名与备注匹配，正文索引用于定位页。
- **文档编辑器**：可编辑 HTML 文档，自动保存（三态提示：未保存 / 保存中 / 已保存）；支持新建（5 个模板：空白 / 每日记录 / 读书笔记 / 灵感卡片 / 清单）、附件、双向链接（输入 `[[文档名]]`）。
- **块级菜单（飞书式）**：编辑器里任意段落左侧出现手柄——点击弹出格式菜单（正文 / H1–H3 / 有序 / 无序 / 待办 / 代码块 / 引用 / 分隔线 / 缩进 / 复制块 / 删除块），拖动手柄可把整块移到任意位置。
- **选区工具条（飞书式）**：选中文字后浮出格式条——粗体 / 斜体 / 下划线 / 删除线 / 行内代码 / 链接 / 字体颜色 / 高亮色 / 清除格式。
- **插入能力**：任务清单、代码块、图片（也可直接把图片拖进编辑区）、双向链接、表格、思维导图（输入缩进文本自动生成 SVG 树状图）、嵌入多维表。
- **查找替换**：编辑器内 Ctrl/Cmd+F，支持上一个 / 下一个 / 替换 / 全部替换。
- **单篇版本**：「🕘 版本」可查看并回滚这篇文档的历史版本。
- **导出 Markdown**：单篇文档可导出 `.md`（正文转换 + 附件清单）。
- **纯文字转文档**：一条碎碎念笔记可一键转成可编辑文档，原文进回收站可还原。

### 3.3 主页（Notion 式仪表盘）

- **23 种板块**，可在「＋ 添加板块」里挑选。弹窗把 23 种按用途分成 5 组（排版 5 / 图文 3 / 卡片导航 6 / 时间待办 7 / AI 2）**一次性平铺**出来，每组带标题与数量；顶部有搜索框与分组胶囊（点一下滚到那组），双列网格点一下即添加：

  | 类型 | 说明 |
  |---|---|
  | 标题 / 文本 / 引用 / 公告栏 | 大中小标题、多行文字、签名引用、带图标的彩色提示条 |
  | 图片 / 多列图文 / 快捷入口 | 单图配说明；两列或三列图文（可放日期钟、倒计时）；常用文件或分类摆成小卡 |
  | 自动分区 / 导航列表 / 月份列表 | 按分类自动生成「标题 + 画廊卡片」；全部分类导航；12 个月一览 |
  | 时间进度条 / 日期钟 / 倒计时 | 年季月周日已过百分比（虚线胶囊）；翻页钟式大日期；距目标日期还剩几天 |
  | 时间线 | 按创建时间倒序、按月分组的时间轴，最近 12 条，点条目直达 |
  | 本月日历 / 待办清单 | 当月日历网格、今天高亮；可打勾任务清单 |
  | 置顶文档库 / 分类统计卡片 / 统计看板 | 自动列出置顶文档；每个一级分类一张淡彩卡片显示数量与占比；看板汇总条目总数、本周新增、标签云、高频打开 Top10、存储分布 |
  | AI 资讯 / AI 助手 | 每天真实 AI 新闻；接大模型直接对话 |
  | 视频网页 / 分隔线 | 嵌入 B 站、YouTube 或网页；划分内容区域 |

- **顶栏显示空间名称**：主页顶栏面包屑不再写「主页」，而是显示当前空间名称（点一下即改名，与侧栏空间名同一份数据）；分类页仍显示分类路径。
- **默认布局**：置顶文档库 + 时间进度条 + 本月日历 + 月份列表 + 「每日挑战」「最近任务」两个待办板块，首次打开自动生成；一旦你自定义过就再也不会被覆盖。顶栏已经显示空间名，正文不再重复放同名大标题（老版本里那块占位标题会自动移除一次）。
- **板块编辑模式**：右上「✏️ 编辑主页」进入——板块可拖拽排序、▲▼ 上移下移、编辑、复制、删除、添加。分享版只渲染内容，隐藏编辑条。
- **日历待办按天独立**：点日历里任意日期，可看当天待办并增删；点行即完成（打勾），已完成会显示删除线；日历格上的圆点按当天清单判断。数据存 `state.calDayTodos['YYYY-MM-DD']`，旧版统一清单会一次性迁移到今天。弹窗下半部分还有「📥 当日新增」——按 `created` 列出那天收进来的笔记 / 文件，点一下关掉弹窗直接打开。
- **统计看板**：主页「📈 统计看板」板块显示三个数字（条内容 / 本周新增 / 个分类）、标签云、高频打开 Top5 与存储分布条，底部「在弹窗里看完整看板」可打开独立弹窗（标签全展开、Top10 完整、可点条目直达）；命令面板也能直接打开。数字全部从 `state` 现场聚合，不做复杂分析；「高频打开」按 `item.opens` 累计次数排，没有累计过就写「最近打开」。
- **背景自定义**：主页顶部栏背景、每个分类页的横幅背景都能单独上传 / 清除；设置里还能把图片设成整页背景（内容区自动加半透明遮罩保证可读）。
- **知识漫游入口条**：主页板块上方一条「🧭 知识漫游」——选范围（全部或某个分类）+「开始漫游」，逐张翻看知识点，支持上一个 / 下一个 / 随机 / 打开原文，会记住上次选的范围。
- **AI 资讯**：见 3.7。
- **AI 助手**：见 3.7。

### 3.4 搜索、视图与整理

- **搜索**：关键词直接搜标题、正文、文件名、标签；支持语法：
  - `#标签` —— 按标签过滤
  - `类型:note` / `类型:photo` / `类型:file` / `类型:link` / `类型:pdf` / `类型:html`（也可写 `type:`，类型名支持中文：文字、照片、图片、链接、文件、网页）
  - `夹:分类名`（也可写 `folder:`）—— 按分类路径匹配
  - 结果给出命中片段高亮并按相关度排序；有搜索历史；Esc 清空收起。
- **进入与退出搜索**：只有点了搜索框并输入内容才会切到结果页——浏览器自动填充、刷新后还原的输入框文字都不会误触发；结果页不再显示横幅和「记点什么」输入条。输入框右侧的 ✕ 或 Esc 一次清空并回到之前的主页 / 收纳夹。
- **排序 6 种**：最近创建 / 最早创建 / 最近打开 / 名称 A→Z / 名称 Z→A / 自定义排序（选「自定义」后可拖拽插入调整顺序）。
- **标签栏**：条目上的标签自动汇总成一条标签栏，点标签即筛选。
- **命令面板**：Ctrl/Cmd+K 一个输入框搞定「找条目 / 找分类 / 执行命令」。
- **批量管理**：进入多选后勾选或全选，可批量移动、打标签、置顶、取消置顶、删除，也可把勾选的文档批量合并。
- **卡片菜单**：每张卡片的「⋯」直出常用操作（打开 / 置顶 / 重命名 / 移动 / 删除等），主页分区还能上移下移排序，手机上长按同样可调。
- **回收站**：删除进回收站可还原，30 天后自动清理（含图片/文件数据），侧栏显示数量。
- **历史快照**：整箱每 3 分钟最多留一份，最多存 8 份（总上限约 1.8MB），可查看并回滚。
- **全局撤销**：Ctrl/Cmd+Z 撤销最近 20 步（删除、移动、批量操作、编辑主页板块等）。

### 3.5 外观

- **主题色**：设置里一个取色器（默认海蓝，可点开色盘取色或直接填 HEX），即时生效。它染的是整套装饰色——背景渐变、卡片、阴影、按钮底色、进度条——只偏移色相、不动明暗结构，深色模式会自动改用更亮的变体保证对比度。旧版那 6 个「主题预设」色点已按反馈移除，老用户选过的预设会自动迁移成等价的主题色，外观不变。
- **主题色与文字色分离**：主题色只影响背景、按钮底色、进度条等装饰；文字色只影响所有文字与按钮文字，互不覆盖；文字色可一键恢复默认，换主题色不会重置文字色。
- **字号四档**：小 / 标准 / 大 / 特大。
- **深色模式**：右下悬浮工具球 →「🌙 深色模式」切换，会跟主题色一起生效，深浅两套都由 `--ink` 系列变量保证对比度。
- **开屏页**：内联在 `index.html`（脚本未加载也能绘制）——薄荷白底 + 纯色模糊泡泡漂移 + ✦ 闪烁 + Logo 卡弹性入场，点击任意处、「跳过 ›」或约 1.6 秒自动淡出，Logo 与标题读取你的头像和空间名。
- **悬浮工具球（右下 🧰）**：一键展开 HTML/PDF 文库（带文档数）、回收站（带数量）、导出备份、导入备份、深色模式。
- **移动端适配**：手机上侧栏变抽屉、工具栏收成图标、长按代替右键菜单。

### 3.6 数据、备份与同步

- **本机存储**：文字数据 → `localStorage`；照片 / 文件 / 头像 / 背景 / 文档 → `IndexedDB`。
- **JSON 备份**：一键导出整箱（含图片与文件内容），也可导入恢复。
- **GitHub 云端（可选）**：填 Owner / Repo / Branch / 目录 + Personal Access Token（可脱敏显示），支持测试连接、同步自检、立即同步、拉取并合并、覆盖式恢复；开启「自动同步」后改动约 1.5 秒自动上传，其他设备的改动会自动拉取合并。
- **多端同步机制**：可靠上传、远程变更检测、逐条合并、定时轮询。
- **单文件缓存**：可选择「清理缓存，只留云端」——卡片仍在原位，点开阅读或编辑时按需拉取；也可一键列出并清理本机超过 5MB 的大文件缓存。
- **存储面板**：统计浏览器占用（文字 / 图片 / 文件 / 快照），可清理孤立数据、查看历史版本。

### 3.7 AI 能力

- **AI 资讯**（主页板块）
  - 真实 RSS：服务端抓取 8 个源（量子位、InfoQ、雷峰网、少数派、Solidot、TechCrunch AI、The Verge AI、Ars Technica AI），每源最多 20 条、合并后最多 60 条候选；无服务端时前端回退 `api.rss2json.com`。
  - 展示：默认按重要性评分排序（AI 相关源加权、热点词加分），可切换按时间；默认显示 12 条，可展开到 40 条。
  - 刷新：`no-store` 实时拉取，按标题去重合并，并明确提示「本次新增 N 条 / 源站暂无新文章」。
  - 存档：按天存档最多 60 天，每天最多 40 条；「🗂 存档」弹窗可按天查看、删除、导出，存档里整行标题可点开原文。
- **AI 助手**（主页板块 + 设置里的「🤖 接入大模型」）
  - 任何 OpenAI 兼容接口：11 个服务商预设（DeepSeek / 智谱 GLM / 硅基流动 / 百度千帆 / 腾讯混元 / 火山引擎豆包 / 通义千问 / Moonshot / OpenAI / Gemini 兼容层 / OpenRouter）+ 自定义。
  - 对话：流式逐字显示，Enter 发送 / Shift+Enter 换行，可「🧹 清空对话」，可勾选「让 AI 参考我的资料」（把分类与条目标题，最多 30 条作为上下文）；板块右上「⚙ 配置」与设置里的「保存配置 / 测试连接 / 清除密钥」等效。
  - 密钥与对话只存本机独立键（`ovovv_llm_cfg_v1` / `ovovv_llm_chat_v1`），不进百宝箱数据、分享版或云端同步；请求经 `/api/llm` 转发以避免跨域，服务端不保存密钥。
  - **零成本起步**：智谱 GLM-4-Flash、百度 ERNIE-Speed-8K、腾讯混元-Lite、硅基流动 9B 以下小模型为永久免费；火山引擎豆包每天重置免费额度；Gemini / OpenRouter `:free` 免费但需国际网络（政策以各官网为准）。

### 3.8 分享

- **三种导出**（设置 →「📤 分享链接」）：
  1. **公开全部内容** —— 笔记、照片、文件都能看；
  2. **只展示结构** —— 别人只看得到分类与文件名，正文、照片、文件内容全部隐藏；
  3. **空白百宝箱（不含数据）** —— 不带任何个人数据，别人打开可自己用。
- **单文件分享版**：导出时读取服务端原始页面，把全部 CSS / JS / 附件内联成一个 HTML，零外链；GitHub 配置、Token、API 密钥始终被剥离。约 6MB（含 5MB 附件）。
- **复制访问链接**：设置里点「复制当前访问链接」，复制的是线上地址 + `sharecode`；无论从线上还是本地打开，都不会把 localhost / 本地文件地址发出去，关闭数据时自动追加 `&nodata=1`。浏览器不允许自动复制时会弹出面板给出完整链接手动复制（不再单独显示一行「链接预览」，那条和复制做的事重复）。
- **把最新数据同步到链接**：点「同步我的数据到链接」→ 打包当前数据推到服务端 `/api/share`，之后访客打开链接优先读这份快照（比站点内置数据新）。改动内容后重新点一次即可。
- **访客体验**：没编辑过内容的访客打开链接会自动跟进你的更新（刷新即最新）；访客一旦自己增删改内容，就永远以本地为准，不会被你的更新覆盖。
- **防误推**：当前数据被判定为空箱时，先弹确认框，避免把好数据换成空数据。
- **只读分享版**：`__BOX_SHARED__` 打开时隐藏编辑入口；分享版也不加载初始种子，数据完全来自内联快照。

### 3.9 设置界面

- **入口**：侧栏底部状态行（`#syncLine`，显示同步状态）点一下即开；顶栏齿轮造型 + 居中「设置」+ 关闭 ×。
- **6 张分组卡片**：☁️ 云端同步 / 🎨 外观与显示 / 🤖 接入大模型 / 📤 分享链接 / 💾 存储与缓存 / 📣 关于（更新公告入口）。原「📖 操作说明」卡片已按反馈删除，关键说明改成各卡片底部的一行灰字。字段多的表单（GitHub 仓库、大模型）收进可点开的浅灰子面板，手机窄屏自动单列。
- **云端同步卡片**底部的灰字直接写清仓库路径（`treasure-box/state.json` 与 images/、files/ 目录）与 Token 只在本地。
- **📣 关于**：一行「更新公告」显示当前版本号（v2.32），点开可重看这一版的新增 / 优化 / 修复说明；已读记录只存本机（`ovovv_wn_seen_v1`），换设备会再看一次。
- 偏好类开关（分享是否含数据、数据范围）只存本机，不进 `state`、备份、分享版或云端同步。

## 六、服务端接口与部署

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/ai-news` | GET | 抓取真实 RSS 并合并（`no-store`），每源 20 条、最多 60 条 |
| `/api/llm` | POST | OpenAI 兼容代理：校验 baseUrl/apiKey/model/messages，拒内网与 http，请求体 ≤256KB、消息 ≤40 条、超时 120 秒；流式透传 |
| `/api/share` | GET / POST / OPTIONS | 分享快照读写：code 仅字母数字 4–24 位（防路径穿越），上限 14MB，同 code 3 秒限频，支持 gzip 与 CORS |
| `/health` | GET | 健康检查返回 `ok` |
| `/favicon.ico` | GET | 返回 204，避免日志噪音 |

- 本地：`npm start`（`PORT` 环境变量可改端口，默认监听所有网卡）。零依赖，Node 16+。
- Netlify：`netlify.toml` 把 `/api/ai-news`、`/api/llm` 重定向到 `netlify/functions/`；`/api/share` 由 `server.js` 提供，因此部署形态需为 Node 服务（当前线上即如此）。Netlify 版 `llm.js` 为非流式缓冲返回。
- 静态资源：`index.html` 不缓存，`css/*` `js/*` 缓存 1 小时；`data/seed.js` 走 gzip。

## 七、怎么改 / 加功能

1. **先定位功能**：对照第四章找模块。例如「搜索结果排序不对」→ `js/20-search-ui.js`；「卡片样式不好看」→ `css/03-home-main.css`。
2. **改完保存刷新即可**，没有构建步骤、没有打包。
3. **新增功能**：在 `js/` 新建一个文件（序号接着排，如 `48-xxx.js`），在 `index.html` 末尾按顺序补一行 `<script>`。
4. **命名规则**：`两位序号-英文短名`，序号即加载顺序；同一功能尽量收在同一个文件里。

**加载顺序规则**：`00-utils.js` 必须最前；参与首屏渲染的模块（如 `40-home-blocks.js`）必须排在 `36-boot.js` 之前，因为 boot 一加载就 `renderAll()`；`41`–`47` 是首屏之后的增强（开屏、合并、多维表、画布、资讯、大模型、访客跟进），排在 boot 之后。

**三个必须知道的坑**：

1. 顶层 `const` / `let` 不能重名（`$`、`state`、`LS_KEY` 等已占用），重名会让整个文件静默失效。
2. 加载期只能调用排在前面的模块里的函数；函数声明只在本文件内提升。
3. 改了 `state` 必须 `save()`，否则刷新就丢；`save()` 会自动打时间戳并触发多端同步。

**什么时候不该新建文件**：给卡片加按钮改 `11-render.js` / `16-card-actions.js`；加样式改对应 `css/`（新增样式文件时，在 `<head>` 里 `06-interaction.css` 之后加一行 `<link>`，后面的覆盖前面的同名变量）；加新字段到 `02-store.js` 的迁移段落补默认值。

### 8.2 已知限制

- **`file://` 下导出分享版不完整**：浏览器禁止读取本地 CSS/JS，只能内联失败提示。需要完整分享文件时用线上站点或本地服务。
- **分享版是快照，不是实时数据**：想更新给朋友，用「同步我的数据到链接」或重新导出 HTML。
- **分享版体积**：附件会内联，含 5MB 附件时单文件约 6MB，邮件/聊天工具有可能限制。
- **重新部署会重置服务端快照目录**：部署后需要重新点一次「同步」。
- **AI 资讯取决于源站**：源站当天没更新时，刷新只会提示「源站暂无新文章」，不会凭空造内容。
- **条目过多时的性能**：目前有缩略图懒加载，但没有虚拟滚动；上千条时列表渲染会变慢。
- **划线标注只支持可渲染的文档**：HTML / 纯文本 / Markdown / Word 由平台自己渲染，可以划线与批注；PDF 交给浏览器内置阅读器，拿不到文本层，标注页签里会直接说明。
- **标注靠文字定位**：文件被换成另一个版本、那段原文改动过大时，这处标注不会硬套到别处，而是在「标注」页签里标记「未定位」，可以手动删除。
- **公开分享的数据是明文**：任何人拿到链接都能看到快照内容（`nodata=1` 除外），敏感内容别放进公开模式。
- **只有画廊视图**：列表视图切换按钮已在早期版本移除，`tb_view` 里的旧记录会自动迁移为画廊；要看表格形式请用 `34-table-view.js` 的表格视图。
